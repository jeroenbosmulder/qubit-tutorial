# Build your own qubit

An interactive tutorial: an introduction, ten steps, and an epilogue — from a coin flip
to a qubit. No physics background needed: just a coin, a chart, and a stubborn refusal
to throw details away.

**Live version:** open `index.html` in any browser (loads React from a CDN), or enable
GitHub Pages on this repo (Settings → Pages → deploy from branch → root) to get a
shareable URL.

**Files**
- `index.html` — self-contained runnable tutorial (React via CDN + Babel standalone)
- `build-your-own-qubit.jsx` — the React source component (drop into any Vite/CRA project)

**New in this version — the restructured Part I:**
- Step 6, "The mirror twins": the lower half of the Bernoulli disk now arrives by the
  triangle-orientation argument (signed band width = twice the area, sign = the turning
  direction), closing with the state's-own-frame signpost that makes "negative lengths"
  an ordinary coordinate along a reversed axis.
- Step 10, "The ball, in your hands": the Part-I finale in two aha experiments — insert
  a third polarizer between crossed sheets (dark → light, classical interference,
  Poincaré's world) and insert a second half-mirror in an interferometer (chance →
  certainty, single photons, the quantum world).
- The evidence room grew to eight playgrounds and two history exhibits: the view from
  the state (Thales frames, amplitudes as the circle's center, the double cover as
  monodromy), the polarizer bench in full, two-paths-one-particle, and the ball's double
  history before and after quantum — ending at Bell's boundary, the bridge to Part II.
